# 로컬 데모 기록

최종 운영 서비스는 `app/gb-system/`에서 관리합니다. 이 폴더는 사용자가 제공한 초기 화면과 로컬 데모를 보존하며 운영 서버/실제 업무 DB에 연결하는 용도가 아닙니다.

| 파일 | 용도 | 확인 방법 |
|---|---|---|
| `GummyBearing_ERP_Demo.html` | 초기 경보·정비 관리 화면 | 브라우저에서 파일 열기 |
| `rotating_equipment_dashboard_standalone.html` | 회전기 모니터링 화면 | 브라우저에서 파일 열기 |

HTML 2개만 원본 그대로 포함합니다. 합계 약 114KB인 독립 화면 참고 자료입니다. 이전 데모의 판정 기준·화면·저장 방식은 현재 서비스와 다를 수 있으므로 현재 모델 비교와 운영 규칙의 근거로 사용하지 않습니다.

원본 `GB_WEB.zip`은 995,346,845바이트이며 여러 중간 버전이 함께 있습니다. 처음 선별했던 `local-fan-v8/`도 최종 서비스와 역할·이미지·데이터가 겹쳐 이번 경량 PR에서는 제외했습니다. 제외한 34개 파일만 약 91.9MB이며, 원본 ZIP 및 로컬 보관본은 유지합니다.

`provenance.json`은 포함한 HTML과 제외한 ZIP/옛 데모의 출처·해시를 구분해 기록합니다. 저장소에서 웹서비스를 실행하려면 `app/gb-system/README.md`를 따릅니다.
