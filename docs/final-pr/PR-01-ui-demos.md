# PR 01 · 화면과 대표 로컬 데모

담당: `onlynew203-cmyk` · 리뷰·병합: 팀장님 · 파일 목록: `manifests/01-ui-demos.txt`

기준: 운영 v18에서 미사용 자산을 정리한 경량 검토본입니다. 165개 파일이며 `PR-review-01-ui-demos-slim.zip`을 사용합니다.

상태: GitHub PR #30으로 병합됐습니다. 아래 내용은 화면 묶음의 검토 기록이며, 남은 서버·배포·검증은 기존 PR #31에서 함께 마무리합니다.

커밋/PR 제목 제안: `feat: GB system 반응형 화면과 보고서 미리보기 정리`

## 설명 초안

설비 전체 현황부터 공정·설비 상세, 점검·승인·일정 화면까지 최신 웹 화면을 한 소스 트리로 정리합니다. 모바일·태블릿 배치, 상태별 설비 이미지, GB system 브랜딩과 PWA 자산을 포함합니다. 작은 초기 HTML 데모 2개를 보존하고, 현재 서비스와 겹치는 v8 전체 데모는 제외합니다.

최종 수정에는 기록·다가오는 일정·캘린더에서 보고서 미리보기 연결, 승인 의견·검토자·승인 시간 표시, ‘점검 후 대응’ 제목과 캘린더 복귀 날짜 유지가 포함됩니다. v17의 새로고침 개선을 유지한 번들 JS/CSS와 원본을 함께 반영합니다.

이미지·폰트·CSS·JS를 같은 PR로 묶었습니다. 파일 간 참조가 있어 따로 빼면 화면이나 한글 글꼴이 누락될 수 있기 때문입니다. 미사용 브랜드 시안·구형 팬 사진·대응 WebP·이전 번들을 제외하고 최적화 이미지 목록을 남긴 24개 항목으로 정리합니다. 현재 원본/번들 내용과 사용 중인 이미지·폰트는 유지합니다.

## 담당자가 검토할 내용

- HTML/CSS/JS와 이미지·폰트의 참조, 다크/라이트 상태 이미지 전환.
- PC/모바일/태블릿에서 메뉴·마이페이지 이동·알림과 재생 버튼 접근.
- HTML 데모 2개 확인. 이전 데모의 판정 규칙을 최종 운영 규칙으로 설명하지 않기.
- PWA 화면 및 서비스 워커와 서버 경로의 호환성.
- 저장소 루트의 `.gitattributes`를 함께 커밋하기. Windows 자동 줄바꿈 변환으로 번들·배포 해시가 달라지는 것을 막습니다.

## 검증 기입

- 정적 참조·번들/원본 해시·전체 기존 JS 회귀 테스트: `validation.json` 참고.
- 운영/체험 공개 변경 파일 18개 응답 해시 일치: `deployment-verification.json` 참고.
- 실제 보고서·승인 화면은 배포 대화의 v18 검증 증빙으로 확인. 이번 PR 검사에서 모든 실제 기기를 다시 촬영하지 않았습니다.
- [ ] 담당자와 팀장님이 PR #31 병합 전 화면·서버·배포 묶음의 통합 동작을 최종 검토.

공동 개발한 결과를 이 PR 담당자가 화면 관점에서 검토·정리했습니다. 서버와 DB는 PR #31의 02·03 검토 묶음에 있으며 화면 PR 하나만으로 전체 서비스 실행이 완료되지는 않습니다.
