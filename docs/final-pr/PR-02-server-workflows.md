## 설명 초안

로그인 세션과 담당 공정 범위에 맞춰 설비·점검·일정·승인·알림 정보를 조회하고 기록하는 서버 코드를 추가합니다. 점검 작성과 완료 승인, 알림함·이메일·PWA 전송 구성, 개인 체험 재생 및 엑셀 출력 기능을 포함합니다.

반복 인증 저장소 초기화와 목록별 부가정보 조회를 줄이고 정적 파일/CSV 전송을 개선한 코드를 함께 포함합니다. 요청의 인증·권한 범위와 처리 결과를 함께 검토할 수 있도록 Python 서버 모듈은 한 PR이 담당합니다.

보고서에는 담당 공정과 설비·기록 ID에 맞는 승인 정보만 연결합니다. 최신 수정은 보고서 조회 기능을 추가하면서 v17의 연결 대기열·내용 해시 기반 캐시 처리를 보존합니다.

서비스용 입력 CSV/JSON은 재현용 샘플이며 운영 MySQL 덤프·실제 비밀번호·세션은 포함하지 않습니다. 공개 이미지/글꼴은 병합된 PR #30에 있습니다. 같은 PR #31의 별도 커밋에 Docker·로컬 Compose·DB 구조와 추가 스키마·31개 회귀/통합 테스트 파일·빌드 도구·검증 문서를 포함합니다. 서버와 실행 환경의 의존성을 한 PR에서 함께 확인할 수 있습니다.

현재 런타임이 읽지 않는 표 형식 CSV 사본 5개를 제외했습니다. 동일 내용을 담은 JSON, 원본 분석 CSV, 재생 시계열과 `tools/build_db.py`는 남겨 샘플 재생성과 기능을 유지합니다. 서버 모듈은 각각 인증·권한·승인·알림·전송 역할이 있어 개수만 줄이기 위해 합치지 않았습니다.
