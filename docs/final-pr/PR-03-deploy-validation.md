## 설명 초안

최신 서비스의 Docker 빌드 설정, DB 구조와 추가 스키마, 회귀 테스트와 배포 확인 문서를 한 묶음으로 정리합니다. 중복된 미리보기·백업·임시 결과는 Git에서 제외하고, 검토 후보가 작업 원본과 같은지 확인하는 파일 목록과 도구를 추가합니다.

특정 이전 환경용 화면 fixture, 운영 권한 probe, 고정된 날짜별 일정 확인과 빈 테스트 안내 5개를 제외했습니다. 유효한 회귀/통합 테스트 31개 파일, 스키마, 실행 문서와 검증 근거는 유지합니다. `pr-exclusions.json`에 파일별 제외 이유를 기록해 이후 후보 갱신 시 제외 파일이 다시 들어오지 않도록 합니다.

Docker 빌드 입력과 DB 구조는 실제 실행에 직접 영향을 주므로 테스트와 함께 검토합니다. 운영 DB의 계정·업무 기록·세션과 비밀 파일은 저장소에 넣지 않습니다. DB용 mock seed는 새 로컬 연습 DB 전용입니다.

`compose.local.yaml`과 `tools/start_local.py`로 `outputs/`가 없는 클론에서도 로컬 검토 환경을 시작할 수 있습니다. 새 빈 DB만 초기화하고 재실행 시 데이터를 유지하며, 기존 AWS/검토 환경과 다른 볼륨을 사용합니다. 로컬 환경은 메일·푸시 발송을 끕니다. 화면 빌드 도구·설정·잠금 파일도 포함합니다.
