발표 설명 — B 2/3을 대표 운영 규칙으로 선택한 이유

1. 이번에 선택한 것은 무엇인가

N=20 · 연속 4회 · 고정 복합 B 방식 2/3을 대표 운영 규칙으로 선택했음.
같은 축의 RMS·첨도·Peak 중 2개 이상이 각각 초기 상한을 4회 연속 초과하면
그 시점을 P로 잡고, 수평·수직 중 어느 한 축에서 성립하면 설비 경보로 봄.

이는 수치가 가장 높은 최적 모델을 자동으로 뽑았다는 뜻이 아님.
프로젝트에서 운영 경보로 설명할 상황을
“초기 상한을 넘는 변화가 여러 특징에서 연속으로 확인되는 경우”로 정한 선택임.
어떤 특징과 축에서 몇 회 초과했는지를 현장 판단 근거로 전달할 수 있음.

2. 고장까지 진행한 실험이므로 증가 방향을 보는 것이 타당한가

초기 상태보다 높은 진동 특징값이 반복되는 상황을 감시 목표로 삼는 것은 가능함.
다만 고장까지 진행한 실험이라는 이유만으로 모든 특징이 시간에 따라 단조 증가한다고
전제하면 안 됨. 첨도는 손상 진행과 함께 증가한 뒤 감소할 수도 있는 지표임.

고정 B 방식은 상승 추세 검정이 아니라 초기 상한 초과 검정임.
증가분 MD도 max((현재값−초기평균)/초기SD, 0)을 사용함.
예를 들어 초기 평균이 10이고 값이 12에서 11로 내려와도 양의 편차가 남음.
따라서 “상승 추세만 탐지함”보다 “초기 기준의 위쪽 이탈을 감시함”이 정확함.

3. 더 빠른 P가 항상 더 좋은 것은 아닌 이유

우리 선행시간은 실험 종료 시각−P임. 실제 결함 시작 라벨에 대한 탐지 지연이 아님.
P가 빠르면 이 수치는 커지지만 정상 변동, 운전 상태 변화, 실제 열화 중 무엇을
포착한 것인지는 이 숫자만으로 구분할 수 없음.
매우 이른 시점부터 자주 경보하는 규칙도 높은 선행시간과 지속률을 만들 수 있음.

또 지속률의 분자는 모델별 이상 조건이고, 평가 구간도 각자의 P부터 시작함.
두 지표가 높다는 결과를 고장 예측 정확도나 낮은 오경보율의 증거로 바꾸어 말하지 않음.

4. 같은 N20·K4에서의 실제 비교

방법                  미경보       최소 선행시간       최저 이상 지속률
고정 RMS               0/6              19분               48.26%
고정 B 1/3             0/6              19분               52.00%
고정 B 2/3             0/6              14분               78.63%
고정 B 3/3             2/6              미산출              미산출
이동 RMS               2/6              미산출              미산출
이동 B 1/3             1/6              미산출              미산출
이동 B 2/3             3/6              미산출              미산출
이동 B 3/3             6/6              미산출              미산출
원본 마할라노비스       0/6              17분               84.08%
증가분 마할라노비스     0/6              17분               41.57%
IF 직접 3σ             0/6              14분               23.42%

미경보가 있으면 전체 6개의 최소·평균을 미산출로 두었음.
경보가 난 베어링만의 결과는 CSV의 conditional_* 열에서 별도로 확인 가능함.
각 방법의 이상 기준이 다르므로 이 표는 기술통계 비교이며 정확도 순위가 아님.
IF 자동 판정은 6번에서 별도 비교하며 이 전체 비교에는 직접 3σ 방식만 포함함.
IF의 지속률은 수평·수직 6개 특징 통합 점수 기준이며, 나머지는 축별 이상 판단의 OR임.
입력 결합 방식이 다르므로 IF의 최초 경보축이나 축별 지속률은 산출하지 않음.

5. B 2/3을 대표 운영 규칙으로 삼은 구체적 근거

- RMS보다 전체 최소 선행시간은 5분 짧지만 최저 OR 지속률은 30.37%p 높았음.
- B 1/3보다 전체 최소 선행시간은 5분 짧지만 최저 OR 지속률은 26.63%p 높았음.
- B 3/3은 2개에서 경보가 없었지만 B 2/3은 비교한 6개 모두에서 경보가 있었음.
- 통합 IF 직접 3σ도 6개 모두에서 경보가 있었고 최소 선행시간은 14분으로 같았음.
  최저 이상 지속률은 B 2/3 78.63%, 통합 IF 23.42%였음.
  각 방법의 이상 정의와 P 이후 구간이 다른 기술통계 비교이며 정확도 우위의 증거는 아님.
- 같은 축에서 여러 특징과 연속 횟수를 함께 확인하므로 근거를 명시적으로 설명할 수 있음.
  다만 RMS와 Peak는 상관될 수 있어 독립된 두 증거라고 주장하지 않음.
- 주어진 N20·K4와 선택 집단에서 조기 반응의 일부를 양보하고 지속 확인을 중시한 선택임.
  특정 가중 점수로 최고의 모델을 입증한 것이 아니며 가중치 점수는 이번 10번에서 제거했음.

원본 MD의 17분·84.08%는 B 2/3의 14분·78.63%보다 모두 높음.
이 사실을 숨기지 않고, 다루는 변화 방향과 운영 설명의 차이를 함께 제시함.
대표 운영 규칙은 프로젝트가 설명하려는 경보 상황에 맞춘 선택이고,
원본 MD는 감소·특징 조합 이탈까지 포함하는 상태 변화 탐지 비교군으로 남김.

전체 최소값의 차이 5분이 모든 베어링에서 5분씩 늦어진다는 뜻은 아님.
Bearing3_2에서는 RMS P172에서 B 2/3 P2029로 크게 늦어졌음.
초기 경보 구간을 실제 열화라고 판별한 것은 아니므로 이 조기성 손실도 공개해야 함.

6. 원본 MD와 증가분 MD를 비교한 의미

9번은 N20·K4의 원본 MD, 증가분 MD, 고정 B 2/3 세 조건만 비교함.
Bearing3_4의 P는 원본 MD55, 증가분 MD1006, 고정 B 2/3 1421임.
원본 MD가 처음 반응한 52~55번째의 수평 세 특징은 초기 평균보다 낮은 방향이었음.
그 변화도 상태 변화일 수 있으므로 정상 또는 오경보로 확정하지 않음.

증가분 MD의 최저 지속률 감소는 원본 MD 결과가 위쪽 이탈만으로 유지되지는 않음을 보여줌.
그렇다고 원본 MD가 틀렸다는 증거가 되는 것은 아님.
편차를 0으로 잘라 점수의 분포가 바뀌었는데 기존 F 상한을 유지했으므로
동일 오경보 확률을 맞춘 방향성 실험도 아님. 공분산 교차항 때문에
증가분 MD 점수가 항상 원본 MD보다 작아진다는 보장도 없음.

7. IF와 P 정의

이번 노트북 IF는 수평 RMS·첨도·Peak와 수직 RMS·첨도·Peak 6개 특징을
하나의 모델에 입력함. 각 특징은 해당 N개 초기 평균과 표본 표준편차(ddof=1)로 표준화함.
베어링별 트리 100개, seed42, max_samples=N, contamination='auto', n_jobs=1임.
직접 상한은 초기 -score_samples 평균 + 3×점수의 표본 표준편차(ddof=1)임.
상한보다 큰 점수를 이상으로 봄. ddof=0 실험 및 이전 축별 300개 트리 결과를 대체한 설정임.
6개 특징의 통합 점수로 판단하므로 H/V OR 결합이나 최초 경보축·축별 지속률은 없음.

자동·직접 IF 모두 P는 연속 K번째 확인 완료 시점임.
Bearing1_5 직접 IF는 35·36·37·38번째 초과 → P38 → 종료52 대비14분임.
N20·K4 직접 IF는 6개 모두 경보가 발생했음. 베어링별 결과는 다음과 같음.

베어링       P 측정번호     종료 대비 선행시간      통합 IF 지속률
Bearing1_5       38              14분                100.00%
Bearing2_1      456              35분                100.00%
Bearing2_2       51             110분                 23.42%
Bearing2_3      131             402분                 94.79%
Bearing3_2     2175             321분                 51.55%
Bearing3_4      971             544분                 49.36%

6번에서는 N15 통과 8개와 N20 통과 6개 각각에 대해 K=1~8을 비교함.
N15·K4는 Bearing1_3가 미경보로 7/8 경보이며, 경보가 난 7개에 한정한 조건부
최소 선행시간은 14분, 최저 지속률은 21.43%임. 전원 경보 수치와 혼용하지 않음.
자동 판정의 학습 구간 이상 비율은 6번 CSV calibration 행에서 확인할 수 있음.
이 비율은 baseline에 대한 진단이며 실제 오경보율로 해석하지 않음.

통합 IF에는 적용되지 않는 지표임.

9. 적용 범위와 다음 검증

초기5~50개에서 수평·수직 RMS와 첨도 네 MK p가 모두 0.01 이상이면 팀 기준 통과임.
동률·연속성 보정 양측 정규근사이며 자기상관 보정은 하지 않았음.
작은 N에서는 검정력이 낮을 수 있고 p≥0.01이 정상·안정성·정밀도 인증은 아님.
N20 통과는 위 6개, N15 통과는 8개, 공통 통과는 6개임.
8번 공통 집단 비교의 감시 시작만 모두 21번째로 맞췄음.
6번 IF 독립 집단 비교는 N15의 16번째, N20의 21번째부터 각각 감시함.
N20과 K4 자체도 이번 팀 공통 설정이며 전역 최적값으로 주장하지 않음.

이번 선택은 분석한 동일 집단에서 내린 운영 판단임.
이제 규칙을 고정한 뒤 별도 베어링·운전 조건과 현장 확인 기록으로 점검해야 함.
현장 화면의 지속률은 미래 종료까지가 아니라 경보부터 현재까지 또는 최근 창에서
계산해야 하며, 이 노트북의 종료 대비 선행시간을 실시간 남은 수명으로 보여주면 안 됨.

10. 발표 문장 예시

“초기20개를 공통 참조구간으로 삼고, 팀의 추세 검증 기준을 통과한6개 베어링을 비교했습니다.
가장 빠른 경보를 곧바로 실제 열화 시작이라고 볼 수 없어,
초기 상한 초과가 같은 축의 여러 특징에서 반복 확인되는 상황을 대표 경보로 정했습니다.
이에 따라 N20·연속4회·고정 B 2/3을 대표 운영 규칙으로 선택했습니다.
이 규칙은6개 모두에서 경보가 발생했고 종료 대비 최소14분, 최저 OR 지속률78.63%를 보였습니다.
원본 마할라노비스의 두 수치는 더 높았지만 감소와 조합 변화까지 포함하는 결과입니다.
따라서 이번 선택은 최적 모델의 입증이 아니라 운영 목적과 설명 가능성을 고려한 규칙 채택입니다.”
